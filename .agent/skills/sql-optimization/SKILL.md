# Patrones de Optimización SQL

Transforma consultas de base de datos lentas en operaciones ultrarrápidas mediante optimización sistemática, indexación adecuada y análisis de planes de ejecución.

## Usa esta habilidad cuando

- Depures consultas que tardan mucho en ejecutarse.
- Diseñes esquemas de base de datos de alto rendimiento.
- Optimices los tiempos de respuesta de la aplicación.
- Reduzcas la carga y los costos de la base de datos.
- Mejores la escalabilidad para conjuntos de datos crecientes.
- Analices planes de consulta EXPLAIN.
- Implementes índices eficientes.
- Resuelvas problemas de consultas N+1.

## No uses esta habilidad cuando

- La tarea no esté relacionada con patrones de optimización SQL.
- Necesites un dominio o herramienta fuera de este alcance.

## Instrucciones

- Clarifica metas, restricciones y entradas requeridas.
- Aplica las mejores prácticas relevantes y valida los resultados.
- Proporciona pasos accionables y verificación.
- Si se requieren ejemplos detallados, consulta `resources/implementation-playbook.md`.
