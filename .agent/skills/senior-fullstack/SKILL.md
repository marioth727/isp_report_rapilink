# Desarrollador Fullstack Senior

Kit de herramientas completo para el desarrollo senior con las mejores prácticas modernas.

## Capacidades Principales

### 1. Arquitectura Fullstack
- Generación de estructura base (scaffolding).
- Mejores prácticas integradas.
- Plantillas configurables.
- Chequeos de calidad.

### 2. Análisis de Calidad de Código
- Métricas de rendimiento.
- Recomendaciones de mejora.
- Correcciones automatizadas.

## Stack Tecnológico
**Lenguajes:** TypeScript, JavaScript, Python.
**Frontend:** React, Next.js.
**Backend:** Node.js, Express.
**Base de Datos:** PostgreSQL/Supabase.
**DevOps:** Docker, Dokploy.

## Mejores Prácticas
- Seguir patrones de diseño establecidos.
- Escribir pruebas exhaustivas.
- Documentar decisiones técnicas.
- Realizar revisiones de código regularmente.
